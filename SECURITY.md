# Crypto Price Tracker - Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

**Please DO NOT open a public issue for security vulnerabilities.**

If you discover a security vulnerability, please email:

- **security@example.com** (replace with actual contact)

Include the following information:

1. Description of the vulnerability
2. Steps to reproduce
3. Potential impact
4. Suggested fix (if available)

We will acknowledge your report within 48 hours and work on a fix as soon as possible.

## Security Best Practices

### For Developers

- Never commit `.env.local` or any sensitive files
- Use `npm audit` regularly to check for vulnerabilities
- Keep dependencies up to date
- Review code before merging

### For Users

- Keep your CoinGecko API key private
- Don't share `.env` files
- Use strong passwords for hosting platforms
- Enable two-factor authentication where available

None currently known.
